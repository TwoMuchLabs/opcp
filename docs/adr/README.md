# Architecture decision records

Each record states one decision about OPCP, the options considered and why one was chosen. Records are numbered in the order they are opened and are never renumbered. A record that changes `spec/` or `schema/` is decided through the 14-day review in [GOVERNANCE.md](../../GOVERNANCE.md) section 3; the record links to that pull request.
