# Architecture decision records

Significant decisions about OPCP's design and governance are recorded here, one file per decision, numbered in order. A record is never deleted: a reversed decision gets a new record that supersedes it.

A decision that changes `spec/` or `schema/` is normative. Its record stays **Proposed** until the change has had the public review required by [GOVERNANCE.md](../../GOVERNANCE.md) (at least 14 days) and a maintainer has accepted it.

| # | Decision | Status | Date |
|---|---|---|---|
| [0001](0001-versioning-model.md) | Versioning model for the specification, document formats and package | Proposed | 2026-11-07 |

## Format

Each record states its status (Proposed, Accepted, Rejected or Superseded by NNNN), the date, what it affects, the context, the options considered, the decision and its consequences, and any questions for reviewers.
